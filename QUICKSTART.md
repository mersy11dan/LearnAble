# Quick start

Use the install steps in `README.md`. The demo runs with `npm install`, `npm test`, and `npm run dev`. No API key is required.

The support chat is on the page. Set `VITE_ENABLE_CHAT=false` to hide it. It answers from built-in text. Do not put a model key in a `VITE_` variable.

`experimental/backend/` is not part of this demo and is not started by Docker Compose. `docs/EXPERIMENTAL.md` says what that folder is and what it is not.
